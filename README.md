## 📦 Shipped Products

### 🏃 Runiverse — India's First Gamified Running App
> *Co-Founder & CMO · React Native · Expo · TypeScript · Mapbox · MongoDB*

India's first territory-based gamified fitness platform. Every run claims territory on a live 3D map. Built with GPS-based hex-grid territory segmentation, Fog of War mechanics, clan wars, and community features.

- ✅ **Live on Android Play Store**
- 🌐 Website: [runiverse.fit](https://www.runiverse.fit) — cinematic 3D scroll experience built with Next.js + Three.js
- 📲 App: [Download on Play Store](https://play.google.com/store/apps/details?id=com.imagine_x.Runiverse&hl=en_IN)
- 🏢 SSIP Recognised Startup under Government of Gujarat

**Tech Stack:**
`React Native` `Expo` `TypeScript` `Mapbox` `MongoDB` `Next.js` `Three.js` `GSAP` `Tailwind CSS` `Brevo` `Vercel`
